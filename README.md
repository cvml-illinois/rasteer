# RASteer Project Page

Retain Aware Activation Steering for Concept Erasure in Diffusion Models

Authors: Yongliang Wu, Haori Lu, Yulun Wu, Jinqi Luo, Xingyu Zhu, Yaoyao Liu.

RASteer removes unwanted concepts through activation steering without training or changing model weights. It builds a subspace for retained concepts and adaptively calibrates the erasure direction to balance erasure and preservation. On the I2P benchmark, exposed body part detections decrease from 612 to 13.
